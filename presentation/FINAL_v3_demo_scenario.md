# デモシナリオ + ダミー投入データ一式

## 架空題材設定
- ホテル名：SAKURA RIDGE HAKONE（架空）
- エリア：箱根・芦ノ湖ビュー
- 客室：28室（大人専用・スモールラグジュアリー）
- ターゲット：欧米インバウンドFIT客（35〜55歳・カルチャー志向）
- 課題：直販比率が低く、ADR向上・OTA依存脱却が急務

```
調査目的：SAKURA RIDGE HAKONEが欧米FIT客に対して直販ADR向上を図るための
ポジショニング確立。
```

```

```

```
タブA：AIツール（ライブ実行用）
タブB：バックアップ動画（demo_fullbackup_SAKURA_RIDGE.mp4）

【失敗パターン別対応】
●ネット切断：タブBに即切替 → 「念のため事前収録でお見せします」
●AIエラー：同上
●処理が30秒超えた：「処理中です。事前収録版もご覧ください」→ タブBに切替
●音声ハウリング等：「少々お待ちください」→10秒待機 → タブBへ

【発表後に言う一言】
「本番でもこのように失敗リスクに備えた運用設計をしています。
これが"実用性"の根拠でもあります。」
```
