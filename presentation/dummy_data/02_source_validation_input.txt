# スキル② source-validation への投入データ
# ※スキル①の出力結果をそのまま貼り付けて使用

## 検証依頼

以下の情報について、出典の信頼性・情報の鮮度・根拠の強さを評価してください。

【スキル①出力（例）から引用：競合A施設の情報】
- 施設名：HIGASHIYAMA INN（架空）
- ADR：¥45,000〜¥80,000
- OTA評価：Booking.com 9.2 / 10（口コミ数：1,240件）
- 主な訴求：「正統派京町家を1棟貸し。禅の朝食体験付き」
- ターゲット：欧米FIT、honeymoon層
- 強み根拠：TripAdvisor Travelers' Choice 2024受賞（公式サイト確認済み）
- 弱み根拠：Booking.com口コミより「チェックイン時スタッフが不在だった」★3コメントが15件

【検証観点】
1. 情報ソースの一次性（公式 vs 二次情報）
2. 情報の鮮度（2025年以降のデータか）
3. サンプル数の妥当性（口コミ件数は統計的に有意か）
4. バイアスリスク（OTA評価の操作可能性）
5. 追加確認が必要な情報
