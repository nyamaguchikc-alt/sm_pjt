## 録画区間 詳細シナリオ

### 【収録A】早送り用：スキル①〜⑩（計10スキル）

**画面構成：**
- 左半分：AIツール（Claude / ChatGPT）の入力・出力画面
- 右半分（任意）：テロップ「スキル① 実行中...」

**各スキルの収録手順：**
1. 対応する入力ファイル（01〜10_*.txt）を開く
2. 内容をコピー
3. AIツールに貼り付け → 実行
4. 出力が表示されるまでを1カットで収録
5. 出力を3〜5秒見せてから次へ

**編集指示：**
- 全10スキル分を1本の動画に連結
- 処理待ち時間は2〜3倍速に編集
- 各スキル開始時に画面上部テロップ挿入：
  - 「① competitive-intelligence」
  - 「② source-validation」
  …（⑩まで）
- BGM：なし（または低音量・落ち着いたもの）
- 合計長さ目標：40〜50秒

**保存ファイル名：**
demo_skills01to10_KASUMI_KYOTO.mp4

### 【収録B】バックアップ用フル通し（①〜⑪すべて）

- 収録Aに加えてスキル⑪まで全部通しで収録
- 編集なし（ありのまま）でも可
- 保存ファイル名：demo_fullbackup_KASUMI_KYOTO.mp4

### 【ライブ区間】スキル⑪ tone-style-enforcer

**手順（本番で実行）：**
1. 「11_tone_style_enforcer_input_LIVE.txt」を事前に開いておく
2. プレゼン中、スライド5表示中に実行
3. 全文コピー → AIツールに貼り付け
4. 実行（Enter）
5. 出力表示まで待つ（10〜20秒）
6. 出力が出たら画面を会場に向ける・説明する

**失敗時の切り替えセリフ：**
「念のため事前に収録したものをお見せします。出力内容は全く同じです。」
→ タブBに切り替えてバックアップ動画を再生
