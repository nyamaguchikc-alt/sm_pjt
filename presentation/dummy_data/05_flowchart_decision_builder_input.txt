# スキル⑤ flowchart-decision-builder への投入データ

## 意思決定フロー構築依頼

以下の戦略選択について、意思決定フローチャートを作成してください。

【判断シナリオ：インバウンド販促チャネル選定】

起点：欧米FIT客の獲得を強化したい

分岐1：予算規模
├─ 月額30万円以下 → [A] SNSオーガニック強化ルート
└─ 月額30万円超 → [B] 有料広告+OTA有料露出ルート

分岐2：リードタイム
├─ 即時効果が必要（1ヶ月以内） → Instagram広告 / OTAプロモ
└─ 中期構築でよい（3〜6ヶ月） → SEO / ブランドメディア

分岐3：コンテンツリソース
├─ 撮影素材あり → リール動画制作 → 投稿最適化
└─ 撮影素材なし → まずUGC（口コミ）収集キャンペーン

分岐4：言語対応力
├─ 英語対応スタッフあり → 直接メッセージ対応型SNS運用
└─ 英語対応なし → AI自動応答 + 事前FAQ整備

各分岐の終端に：
- 推奨アクション
- 期待効果（定量）
- 必要リソース
- 次のレビュータイミング
