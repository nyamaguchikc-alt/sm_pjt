# スキル⑦ workflow-automation-agent への投入データ

## 実行ワークフロー設計依頼

スキル①〜⑥の出力結果をもとに、以下の施策を「誰が・いつ・何を・どのツールで」実行するか、
週次運用可能なワークフローに落とし込んでください。

【施策：インバウンド向けInstagramコンテンツ運用】

担当者情報：
- 担当：ホテル事業部 販促担当1名（英語中級、AI活用経験あり）
- 利用可能ツール：ChatGPT / Claude / Canva / Notion / Later（投稿予約）
- 作業可能時間：週4時間以内

ワークフロー設計要件：
1. 週次の投稿計画（何曜日に何を投稿するか）
2. 各投稿の制作ステップ（素材収集→AI生成→確認→投稿）
3. 各ステップで使うAIツールとプロンプトの概要
4. 承認フロー（誰がチェックするか）
5. 効果測定タイミングと指標

【出力形式】
- 週次チェックリスト形式
- Notionテンプレートとして使えるMarkdown形式
- 所要時間を各ステップに明記
